# DEPI-Social-Media-Data-Analysis
A social media data analysis graduation project- DEPI Round 4

Project Idea
Social media plays a major role in daily life, but excessive usage may negatively affect
productivity and time management.
This project analyzes social media usage patterns and their relationship with
productivity levels to identify behavioral trends and possible indicators of digital
addiction.
The analysis will focus on understanding how users interact with social media
platforms, how much time they spend online, and how this behavior affects their
productivity.
The final outcome will be an interactive Power BI dashboard presenting insights and
recommendations for improving digital productivity.

Dataset Source
https://www.kaggle.com/datasets/rockyt07/social-media-user-analysis/data

Project Plan

1. Research & Analysis
The team will study the dataset and define key analytical questions such as:
- How much time do users spend on social media daily?
- Which platforms are used the most?
- Does increased social media usage affect productivity?

2. Data Preparation
Using Excel and Python, the dataset will be cleaned and prepared by:
- Detecting missing values
- Removing duplicate records
- Correcting data types
- Standardizing data formats

3. Data Analysis
Using SQL and Python, the team will analyze the dataset to identify patterns and
insights, including:
- Average social media usage time
- Productivity score distribution
- Relationship between usage time and productivity

4. Dashboard Development
Insights will be visualized using Power BI through an interactive dashboard including:
- Executive Overview: key metrics such as average usage and productivity score
- Usage Behavior Analysis: platform usage and time distribution
- Productivity Impact Analysis: comparison between social media usage and
  productivity levels
